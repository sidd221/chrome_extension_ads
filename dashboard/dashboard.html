Settings

Extraction

Slow scrolling keeps AdScoop within normal browsing speed. It stops by itself if Meta shows a login wall, CAPTCHA or rate-limit message – it never tries to get around them.

CSV export
Image OCR (text inside creatives)

OCR starts only when you press “Read text from image” on an ad. Meta's image links are signed and expire, so re-extract an ad if OCR says the link is dead.

Optional AI analysis your own API key

The local rule-based analysis is the default and needs no key. If you add a key, ad copy is sent to the provider you choose only when you press “Analyse with AI”. You pay that provider directly; AdScoop has no server and no key of its own.

The key is saved unencrypted in this browser's extension storage and is never sent to facebook.com or any site except the Base URL above. Use a key with a spending limit.

Optional video transcription your own API key

Meta usually streams ad video through blob: links the browser cannot download, so a transcript is only possible when a direct video link was captured. Otherwise AdScoop says “unavailable” and lets you paste a transcript.

Your data

Ads live in chrome.storage.local on this computer. Importing a backup merges by Ad ID – nothing is duplicated.

Getting started

  1. Open facebook.com/ads/library, choose a country and search for a business, product or competitor.
  2. Let the results load, then click the AdScoop icon.
  3. Extract New Ads reads every visible ad you have not saved yet. Extract All Visible Ads re-reads everything on screen. Auto-scroll & extract scrolls slowly for you up to the number you choose.
  4. Review the cards here, filter, select, and Export CSV. Open it in Excel or Google Sheets.

What is real data and what is analysis?

  • From the ad Values AdScoop read from the page. Anything it could not see stays empty, with a reason in Extraction notes.
  • Machine-read Text read from an image by OCR or from a video by transcription. It can contain errors and only exists after you ran it.
  • Inferred Conclusions drawn by AdScoop's rules (or by your AI model). Meta does not publish hooks, angles, audiences, funnel stages or objectives. The 1–10 hook score is an estimated heuristic, not a performance prediction. In the CSV these columns start with [Inferred].

Known limits

  • The Ad Library shows no spend, reach or performance for most ads, so AdScoop cannot report them.
  • Landing page URLs, Page IDs and platforms are only captured when the card exposes them.
  • Image and video links are signed Meta CDN links that expire after a while.
  • Meta changes its page layout often. If cards stop being detected, see the README troubleshooting section.
  • Use AdScoop only for what you can already see in your own browser, at normal speed, and in line with Meta's terms.
